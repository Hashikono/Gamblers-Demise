# Gamblers-Demise
A casino tycoon game where you rig slot machines to make more money, but harsher odds drive out the amount of bunnies that come to your casino. Beware, at the end of the day, the White Rabbit forces you to play the same machines you created.

# How to play
1. Download the zip file of the game, extract it and open the HTML file in the latest version of chrome...
2. https://hashikono.github.io/Gamblers-Demise/
